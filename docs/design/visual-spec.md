# Eos 界面的视觉规范（提议）

- 状态：提议，2026-11-28。用户看过 `docs/design/workbench.html` 并认可了这个方向；主题色以后可能换。
- 读者：要修改设计令牌（`web/src/tokens.css`）、基础组件（`web/src/ui/`）和界面 skill 的人。
- 依据：`docs/design/workbench.html`。它是一个不依赖仓库代码的网页，用浏览器直接打开就能点。这份文档和它不一致时，以它为准。

## 原则

1. **克制。** 页面几乎只有黑、白、灰。全站只有一个强调色，只用来表示「等你处理」：标题前的小圆点、卡片上的类型、任务清单里等人的那几行。别的地方不用颜色。
2. **一屏只有一个浮起来的东西。** 当前要处理的卡片有阴影，其余内容平铺在背景上，不加外框。
3. **用留白和细线分区，不用边框和底色。** 列表的行与行之间一条细线；区块之间靠间距。
4. **标题不抢内容。** 区块标题是小号的灰字；卡片的标题才是大字。
5. **主操作是黑色**（暗色主题下是白色）。一组按钮里只有一个主操作，其余是细边框的次要按钮。
6. **状态用形状表达，颜色只做补充。** 选中的选项是黑色细边框加一个实心的勾；进度是五小段。
7. **动效短，而且有含义。** 做完一件事，卡片淡出、下一张补上，对应的任务闪一下。系统设置了减少动态效果时全部关掉。

## 颜色

| 名字 | 用途 | 亮色 | 暗色 |
|---|---|---|---|
| `bg` | 页面背景 | `#f6f6f4` | `#111110` |
| `surface` | 卡片、浮层、对话页的底 | `#ffffff` | `#191918` |
| `ink` | 正文、主按钮的底、选中的边框 | `#191918` | `#ecece8` |
| `ink-2` | 次要文字、区块标题 | `#5d5d58` | `#a4a49e` |
| `ink-3` | 辅助信息（时间、数量、占位提示） | `#93938d` | `#6e6e69` |
| `line` | 细线、次要按钮和选项的边框 | `#e8e8e4` | `#292927` |
| `fill` | 悬停、当前步骤、说明块的底 | `#f0f0ed` | `#212120` |
| `fill-2` | 导航的当前项、进度里没走到的段 | `#e6e6e2` | `#2b2b29` |
| `accent` | 只表示「等你处理」 | `#c8611a` | `#e9955c` |
| `accent-soft` | 任务状态刚变化时闪一下的底色 | `#fbefe5` | `#2b211a` |

- 主按钮上的文字用 `surface`。
- 灰色都带一点暖，不用纯中性灰。
- 成功、失败这类状态色这一版没有用到，需要时另定，不拿强调色代替。

## 字体和字号

- 字体：`"Inter", -apple-system, BlinkMacSystemFont, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", system-ui, sans-serif`。等宽：`ui-monospace, SFMono-Regular, Menlo, Consolas, monospace`。
- 正文行高 1.55。数字用等宽数字（`tabular-nums`）。

| 用途 | 字号 | 字重 |
|---|---|---|
| 卡片标题 | 21px，行高 1.3，字距 -0.01em | 600 |
| 分栏里的任务标题 | 19px | 600 |
| 问题、对话里卡片的标题 | 15px、14.5px | 600 |
| 卡片的引导语 | 14.5px，最宽 62 个字符 | 400，颜色 `ink-2` |
| 正文、任务名 | 14px | 400；任务名 500 |
| 按钮 | 13.5px | 500 |
| 区块标题、状态、次要说明 | 13px | 500（区块标题），400 |
| 卡片顶上的一行信息、时间 | 12.5px、12px | 400 |

## 圆角、阴影、间距

| 元素 | 圆角 |
|---|---|
| 当前卡片、空状态的虚线框 | 18px |
| 输入区（对话的输入框） | 16px |
| 对话里的卡片 | 14px |
| 选项、说明块、浮层 | 12px |
| 按钮、导航项、任务行、页签外框 | 10px |
| 小按钮（图标按钮、文字按钮） | 8px |

| 阴影 | 亮色 | 暗色 |
|---|---|---|
| 卡片 | `0 1px 2px rgba(25,25,24,.04), 0 8px 28px rgba(25,25,24,.07)` | `0 1px 2px rgba(0,0,0,.3), 0 8px 28px rgba(0,0,0,.35)` |
| 浮层（下拉） | `0 2px 6px rgba(25,25,24,.06), 0 16px 40px rgba(25,25,24,.14)` | `0 2px 6px rgba(0,0,0,.3), 0 16px 40px rgba(0,0,0,.5)` |

- 卡片内边距 28px（底部 22px）；窄屏 22px 和 18px。
- 页面左右留白 40px，区块之间 44px；窄屏 16px 和 32px。
- 列表行高 44px。

## 组件

| 组件 | 样子 |
|---|---|
| 主按钮 | 高 36px，圆角 10px，底 `ink`，字 `surface`；悬停时不透明度 0.86 |
| 次要按钮 | 同样大小，透明底，1px `line` 边框，字 `ink-2`；悬停时底 `fill`、字 `ink` |
| 文字按钮、图标按钮 | 高 32px，圆角 8px，没有边框，字 `ink-2`；悬停时底 `fill` |
| 卡片 | 底 `surface`，圆角 18px，卡片阴影，没有边框 |
| 选项 | 一行一个，圆角 12px，1px `line` 边框，内边距 11px 14px；右边一个 18px 的圆。选中：边框 `ink`（视觉上约 1.5px），圆变成实心 `ink` 加白色的勾。不用浏览器自带的单选圆点 |
| 「其他」输入 | 和选项同宽同圆角，高 44px，1px 虚线 `line` 边框；聚焦时变成实线 `ink` |
| 步骤 | 一行小字：范围 — 编码 — 汇总。当前步骤是 `fill` 底的小药丸（高 28px）；走过的步骤前面有一个勾 |
| 分段切换（过程 / 改动） | `fill` 底的外框，圆角 10px，内边距 3px；选中的那一段是 `surface` 底加很轻的阴影 |
| 信息行（改动、测试、评审） | 左边 56px 宽的标签（`ink-3`），右边是值；行与行之间一条 `line` |
| 说明块 | `fill` 底，圆角 12px，内边距 12px 14px，字 13.5px `ink-2` |
| 浮层 | `surface` 底，1px `line` 边框，圆角 12px，浮层阴影，内边距 6px；每项圆角 8px，悬停和当前项是 `fill` 底 |
| 任务行 | 高 44px。左边任务名（等人的前面有一个 6px 的强调色圆点），中间五小段进度（每段 14×3px，走完的 `ink`，正在走的 `ink-3`，等人的那一段用强调色），右边状态（148px 宽，右对齐）。行与行之间一条 `line` |
| 导航栏 | 宽 56px，只有图标（18px），每项 40×40px、圆角 10px；当前项底 `fill-2`。鼠标移上去显示名字 |
| 图标 | Lucide 的画法，线宽 1.8px，颜色跟随文字 |
| 聚焦 | 2px `ink` 的外框，离元素 2px |

## 动效

| 场合 | 做法 |
|---|---|
| 做完一件待办 | 卡片 250 毫秒内淡出并向上移 28px；下一张 300 毫秒内升上来 |
| 对应的任务 | 底色从 `accent-soft` 淡回透明，1.2 秒 |
| 右栏换成任务详情 | 220 毫秒内淡入并从右移入 16px |
| 悬停 | 只变颜色，120 到 150 毫秒 |

系统设置了「减少动态效果」时，以上全部关掉。

## 工作台的布局

| 区域 | 内容 |
|---|---|
| 左：图标导航，56px | 上：工作台、对话、任务、统计、改进、团队约定。左下角：设置。左上角是产品标志的位置 |
| 中：等你处理 | 占满一屏的高度。一个任务一张卡片，上下滚动，滚动时一张一张对齐到顶；不显示滚动条，底部渐变消失。标题右边是「第几件 / 共几件 + 当前任务名」的下拉，和上、下两个小箭头 |
| 右：进行中的任务 | 最多 10 个。点一个任务，这一栏原地换成它的详情，左上角有返回 |

- 两栏各自滚动，互不影响：处理待办时，右边的位置不动。
- 工作台上没有对话。对话是单独的一页，只有一个居中的对话，最宽 760px。
- 等你处理、进行中的任务是两个互不依赖的组件；工作台只决定放哪几块、按什么顺序（参考同一个分支上的 `web/src/workbench/Workbench.tsx` 的 `MAIN_SECTIONS`）。这一版不开放给用户调整。

## 证明不了的

- 这些数值来自一张设计稿，只在工作台和对话两页上用过。别的页面（任务详情、统计、团队约定、设置）用起来是否合适，没有验证。
- 文字和背景的对比度没有逐项计算。
- 窄屏（390 宽）只确认了不横向滚动，没有仔细设计。
