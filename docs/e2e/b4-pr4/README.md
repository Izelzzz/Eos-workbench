## 做法

场景和前几个 PR 相同：团队规则「导出函数要有带 @example 的 JSDoc」只写在 reviewer 模板第 2 版里。

1. 并行跑 3 个 standard 任务。agent 提问时自动回答，任务失败时自动重试。
2. 在浏览器里打开 `#/improve`，点「生成提案」，调用真实的 improver。
3. 打开第一条提案：核对证据和新旧对比，填写备注后批准。
4. 打开第二条提案：先空着理由点拒绝，确认被拦下；再填写理由，拒绝。
5. 分别在 1440 宽和 390 宽下截图，检查页面有没有横向滚动、有没有脚本错误。
