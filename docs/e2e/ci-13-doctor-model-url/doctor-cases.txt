## EOS_MODEL_BASE_URL=[http://127.0.0.1:12345/anthropic]
⚠ 模型接口地址：EOS_MODEL_BASE_URL 指向本机的 127.0.0.1:12345/anthropic：模型请求和模型 key 会发给本机上的这个服务
  怎么修：确认它是你在本机运行的模型网关或测试服务

## EOS_MODEL_BASE_URL=[https://gateway.example:8443/anthropic]
⚠ 模型接口地址：EOS_MODEL_BASE_URL 指向 gateway.example:8443，不是官方接口：模型请求和模型 key 都会发到这台主机
  怎么修：确认这是你信任的模型网关；不需要时删掉 EOS_MODEL_BASE_URL，改用官方接口

## EOS_MODEL_BASE_URL=[http://relay.internal/anthropic]
✗ 模型接口地址：EOS_MODEL_BASE_URL 只能是 https 地址，或者本机的 http 地址（现在是 http://relay.internal）
  怎么修：改正环境变量 EOS_MODEL_BASE_URL（https 地址，或本机的 http 地址，不带用户名和密码）；用官方接口时删掉它

## EOS_MODEL_BASE_URL=[https://u:***@gw.example/a]
✗ 模型接口地址：EOS_MODEL_BASE_URL 里不能带用户名和密码
  怎么修：改正环境变量 EOS_MODEL_BASE_URL（https 地址，或本机的 http 地址，不带用户名和密码）；用官方接口时删掉它
