# 第 4 块 PR2：提案审批 E2E（真实模型）

脚本：`scripts/proposals-e2e.ts`，命令：`node --import tsx scripts/proposals-e2e.ts`。

## 做法

场景和 PR1 相同：团队规则「导出函数要有带 @example 的 JSDoc」只写在 reviewer 模板里（存为第 2 版）。

1. 发起任务 A（standard，sum）。
2. A 还在跑的时候，往数据库写入 3 条针对 developer 模板第 1 版的提案，再通过 Web 接口审批：
   - #1 把这条规则加进 developer 的提示词，**批准**；
   - #2 和 #1 一样基于第 1 版，**批准**，这时它已经过期；
   - #3 **拒绝**。

   生成提案是 PR3 的内容，所以这里的提案是手工写入的。
3. A 结束后，发起任务 B（standard，max），等它结束。
