# 平台：容器内 eos web --host 0.0.0.0，EOS_PUBLIC_URL=https://eos.example.com；端口映射 127.0.0.1:4317 → 容器 4317
## 启动日志
注意：监听 0.0.0.0，能连到这台机器 4317 端口的人都能用 Eos（没有登录）。浏览器只能通过 localhost:4317 或 https://eos.example.com 访问
Eos Web：https://eos.example.com（监听 0.0.0.0:4317，数据目录 /srv/data，日志 /srv/data/logs/eos.log，Ctrl+C 退出）
## 请求 → 状态码（curl 从宿主机发出，打到 127.0.0.1:4317；每行附命令）
GET 本机 Host → 200
    curl http://127.0.0.1:4317/api/tasks
GET Host localhost:8080（宿主机换了端口） → 421
    curl -H Host: localhost:8080 http://127.0.0.1:4317/api/tasks
GET 外部 Host → 200
    curl -H Host: eos.example.com http://127.0.0.1:4317/api/tasks
GET 外部 Host 带默认端口 → 200
    curl -H Host: eos.example.com:443 http://127.0.0.1:4317/api/tasks
GET Host evil.example（DNS 重绑定） → 421
    curl -H Host: evil.example http://127.0.0.1:4317/api/tasks
POST 外部 Host + 外部 Origin，空请求体（通过同源检查，400 是请求体校验） → 400
    curl -X POST -H Host: eos.example.com -H Origin: https://eos.example.com -H content-type: application/json -d {} http://127.0.0.1:4317/api/tasks
POST 外部 Host + http Origin → 403
    curl -X POST -H Host: eos.example.com -H Origin: http://eos.example.com -H content-type: application/json -d {} http://127.0.0.1:4317/api/tasks
POST 外部 Host + 没有 Origin → 403
    curl -X POST -H Host: eos.example.com -H content-type: application/json -d {} http://127.0.0.1:4317/api/tasks
## 代理改写了 Host（Host 是本机地址，Origin 是外部地址）的 403 提示
{"ok":false,"error":"只接受来自本页面的请求：Origin 是 https://eos.example.com，Host 却是 127.0.0.1:4317，反向代理要把原始 Host 传过来"}
## EOS_PUBLIC_URL 带路径
EOS_PUBLIC_URL 只能是 协议://主机[:端口]，不能带路径、查询或用户名：https://eos.example.com/eos
eos 退出码=1
## --host 是具体的非本机地址、没设 EOS_PUBLIC_URL
监听 10.9.9.9 时浏览器的 Host 是 10.9.9.9:4317，不是本机地址；要么改用 --host 0.0.0.0，要么把浏览器用的地址设成 EOS_PUBLIC_URL
eos 退出码=1
## --host 不在本机、设了 EOS_PUBLIC_URL（真正去监听，失败）
Web 服务没能监听 10.9.9.9:4317：EADDRNOTAVAIL
eos 退出码=1
## 没设 EOS_PUBLIC_URL、监听 0.0.0.0 时的启动日志

Eos Web：http://localhost:4317（监听 0.0.0.0:4317，数据目录 /srv/data，日志 /srv/data/logs/eos.log，Ctrl+C 退出）
