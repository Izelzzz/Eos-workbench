# 凭据页（路线图 P0 第 1 项，PR 2）E2E 证据

运行命令：`node --import tsx scripts/credentials-web-e2e.ts docs/e2e/credentials-2`。

脚本先带一个随机主密钥启动真实的 `eos web`，用 Playwright 在页面上依次做：保存两条凭据、替换其中一条、刷新、删除一条，并截图。
然后不带主密钥再启动一次，看页面上的说明。最后在接口响应、服务输出和数据目录里的所有文件里查找凭据的值。

结果 14/14，见 `report.json`。

|---|---|

## 第一次运行发现并修掉的问题

- 390 宽时表格撑出了页面。修法：窄屏隐藏「主密钥指纹」列，单元格不换行。
- 替换 `github.com` 时，类型下拉框还停在上一次选的「模型 API key」，结果把它的类型悄悄改掉了。现在类型默认按名字推算：名字和已有凭据相同就沿用它的类型，用户在下拉框里手动选过的优先。
